GoFrantic preflight returned HTTP 500 for this official `receipt_ref` alone, while `evidence_json` and `report` each produced normal HTTP 200 preflight responses. This blocks the bounty's required receipt verification route despite a succeeded Ausca invocation.
- **Concrete change.** Add one copy-paste Node example to the Agent Inbox skill that initializes `node:crypto` webcrypto, performs the unsigned challenge and signed retry, and prints a redacted checklist with amount, offer bindings, invocation ID, output digest, and receipt URL. This follows directly from the two payment-path failures and the sparse receipt view encountered in this run.
